## Compiler, runtime and Windows headers

MSYS2 UCRT64 distributes GCC, binutils, MinGW-w64 and associated libraries under
their respective GPL, LGPL, runtime-exception and permissive terms. They are
independent packaged tools and retain upstream notices. Exact package versions,
license metadata and source hashes are recorded in
[installer/toolchain-sources.json](installer/toolchain-sources.json).
Per-file notices in those packages/source archives remain authoritative.

The compiled app links GCC/libstdc++ runtime code and MinGW-w64 support code.
The relevant notices are included under `licenses/runtime`, with the
[GCC Runtime Library Exception](licenses/GCC-Runtime-Exception-3.1.txt).
Windows system DLLs and installed system fonts are used, not redistributed.

The installer retains package-provided notices and includes matching source
archives for every bundled compiler package, including split packages sharing
one source archive. See [toolchain notes](installer/TOOLCHAIN-NOTICES.md).
